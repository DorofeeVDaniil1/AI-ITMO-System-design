# Self-review

**Самое слабое:** liveness и эмбеддинги в PoC — mock/fixture. Политику fail-closed это доказывает, качество лиц — нет. Кто будет смотреть только demo — может переоценить готовность.

**Assumptions:** FA = 250k ₽/инцидент; opex edge ~15k ₽/мес на три точки; в эффекте MVP авто-доля ~40% на пике; 50% ручных кейсов — «забыл карту».

**Нерешённые риски:** реальный PAD на наших камерах; согласие и процессы HR; хвост review% убивает охрану при живом FAR=0; sync отзыва при частичном offline кластера edge.

**Ради demo:** детерминированные scores в `events.json`; нет RTSP; турникет = строка в JSON; gallery на трёх «сотрудниках».

**За +2 дня:** поднять InsightFace+PAD на CPU на 1 камере в shadow; калибровка T_allow/M_min на holdout по identity; простой экран очереди для охраны; метрики latency/review в Prometheus-заглушку.

**До prod:** юр. контур и DPIA/аналог; HSM/шифрование шаблонов; аттест edge; нагрузочный прогон 20/мин; контракт с вендором турникета; runbook FA kill-switch.

**Без юр/security review нельзя:** enrollment биометрии, хранение шаблонов, любой UI с чужими лицами, передача кадров в облако.

**Не автоматизировать полностью:** серую зону, stale cache, явные spoof (нужен процесс, не только deny), изменение порогов FAR в проде без holdout.

**Стоп пилота:** любой подтверждённый false accept; review% в пике стабильно >15% при сопоставимом потоке; p95 > 1 с после нормальной infra; охрана загружена не меньше baseline при «успешном» ML.

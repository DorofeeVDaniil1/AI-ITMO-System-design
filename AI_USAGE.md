# AI usage

Работал в Cursor (агент + правки руками). AI разрешён заданием; ниже — где помог, где мешал, что решил сам.

## По этапам

**Понимание и декомпозиция.** Скинул ТЗ, попросил разложить артефакты и скоуп на 4 часа. Полезно: чеклист файлов и напоминание, что PoC не центр оценки. Сам зафиксировал правило: docs-first, ~60–70% времени на дизайн.

**Архитектура.** AI тянул то к «всё на edge», то к тяжёлому центру с стримингом кадров. Отклонил cloud-only на горячем пути (1 с + offline) и «храним все кадры для разбора». Выбрал hybrid сам: инференс на edge, SoT шаблонов/отзыва в центре, кадры по умолчанию не уезжают.

**CV/ML.** Подсказки по стеку (SCRFD / ArcFace / passive PAD) ок как baseline в тексте. Сам убрал LLM из allow/deny — нет калибровки FAR и нормального аудита. Пороги трёх исходов и stale cache → review — моё чтение кейса e-1005, не «модель сама разрулит offline».

**PoC.** AI быстро набросал FastAPI-скелет. Первый матч через близкие demo-векторы сломал happy path (margin слишком маленький) — поймал pytest'ом, ушёл на явный `match_override` в фикстурах: для кейса важнее детерминированная policy, чем игрушечный cosine. Идемпотентность по `event_id` добавил после того, как в черновике повторный POST плодил второй audit open.

**Тесты и доки.** Тесты и структуру docs AI ускорил. Текст правил: без канцелярита, от первого лица, цифры рядом с выводами. AI_USAGE/WORKLOG писал сам по факту сессии. Позже отдельно добил CI, curl в README и правдоподобный latency — уже руками, когда базовый срез уже лежал в git.

**Риски.** AI предлагал общие списки GDPR-стиля. Сжал до 3–4 пунктов, оставил wipe на edge, inversion и «как сказать отказ без emp-id на табло».

## Ошибки AI (полезные)

1. **Открывать при хорошем match в offline.** Без оглядки на возраст кеша. Ломает отзыв уволенного. Исправление: `cache_age` > порога → manual_review даже при высоком score.
2. **Складывать runtime-кадры «на всякий случай».** Лишняя биометрия. В дизайне — шаблоны + короткий crop для review.
3. **LLM в контуре решения.** Звучит модно, для FAR/аудита бесполезно. Вычеркнул.
4. **Хрупкий demo-матчинг.** Близкие векторы → e-1001 уезжал в review. Обнаружил smoke-тестом; зафиксировал scores в `events.json`.
5. **Вода в product.md.** Переписывал под таблицу гипотез и грубый net на цифрах ТЗ.

## Биометрия: как не проглотил небезопасный дизайн

Чеклист против ответов AI: кадры по умолчанию не храним; audit без сырого кадра; fail-closed; серая зона не open; stale cache не open; нет LLM в matcher; удаление/отзыв должен доезжать на edge. Если совет бился с этим — выкидывал.
